# Todo

Capturing and listing the things a user intends to get done. This is home-bird's initial context — the module is deliberately small, but its language is real and binding.

## Language

**Todo**:
A single item the user intends to get done, with a title, a Done state, and a creation time.
_Avoid_: Task, Item, Entry

**Done**:
The state of a Todo whose work is finished. Every Todo starts not Done.
_Avoid_: Completed, Finished
