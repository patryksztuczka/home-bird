# 01: Create an apartment project with a floor plan

**What to build:** Replace the starter experience with a desktop apartment workspace. A user can create an apartment project, provide its required floor plan, and see the uploaded plan as the center of the project editor.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] A user can create an apartment project with a name and supported floor-plan image.
- [ ] The floor plan is required and invalid or unreadable files produce a clear validation message.
- [ ] A successfully uploaded floor plan is retained with the project and shown in the editor.
- [ ] The editor reserves a side panel for controls while keeping the floor plan as its main workspace.
- [ ] The starter Todo interface is no longer the product entry point.
- [ ] The project contract is validated by the same shared schema in the web form and API.
- [ ] An automated test covers project creation, rejected input, and retrieval of the uploaded floor plan without calling external storage.
